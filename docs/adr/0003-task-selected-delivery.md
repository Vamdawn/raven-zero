# 任务选择可选交付组件，通用核心协调生命周期

不同任务的完成条件与交付动作不同，固定的 Git 交付流程不能成为通用框架核心。任务声明完成条件，并可选择客户端已注册的交付组件及参数；客户端执行交付与检查、报告证据，核心协调任务生命周期，调度时匹配所需 Agent 与交付组件的能力。相比全部交由 Agent，这使明确的外部交付步骤可以独立检查与恢复，同时保留无需额外交付组件的任务。

首版提供 `git-pr` 交付组件，代码任务在交付前检查通过、PR 创建并完成交付后检查时结束，不等待 PR 审查或合并。另以生成指定格式的本地报告验证无需 Git 交付组件的任务。

上述首版 PR 交付要求已由 [ADR 0004](0004-git-branch-delivery.md) 替代，改为 Git 提交并推送分支；可选交付组件的架构保持有效。
