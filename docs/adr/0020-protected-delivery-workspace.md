# 通过受保护的交付工作区隔离后续 Agent 写入

工作阶段结束后，客户端将本版成果发布到独立交付工作区，再执行检查、可选交付与文件产物上报；任务工作区与会话身份保留，显式恢复生成新版本，不覆盖既有交付成果。相比依赖回合完成、进程组退出或单独复制目录，从任务启动起由框架控制的外层执行边界保护交付目录及执行记录，且原生审批不能解除这层保护；边界未经核验或发布未完成时不得进入检查与交付。

此决策调整 ADR 0002 的单工作区后续用途与 ADR 0009 的隔离目标：保证 Agent 不能修改正在检查和交付的成果，不承诺原任务工作区不再变化，也不将交付隔离等同于取消所需的全部进程停止确认。macOS 真实 Codex 与 Linux 容器文件实验支持这一设计方向；平台实现、生产权限配置及剩余验收见[隔离契约](../design/delivery-workspace-isolation.md)，尚不代表首版兼容验收全部完成。
