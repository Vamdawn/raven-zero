# SQLite 客户端与 HTTP 验收

2026-10-09，Issue #6，起点及双轴审查基线为 `6eb3a27f711b836093ddc0c323060495db773cbb`。用户确认的测试边界是 `ClientManager`、SQLite 存储公开接口，以及已有 `LocalTaskRunner` 执行／恢复入口。实现约束来自 Issue #6 引用的首版规格、技术栈与交付隔离契约；这些引用版本与本轮起点的内容一致。

环境为 macOS 26.6.1 arm64、非 root GUI 用户、Node.js 24.15.0、pnpm 11.0.9、MySQL 8.4。实现前 `pnpm doctor` 与 `pnpm test:mysql-smoke` 通过。MySQL 用例创建私有 socket-only 实例和临时数据库，不连接个人运行中的数据库；SQLite 与 Git 资源同样位于独占临时目录。

## 已运行的行为

| 场景 | 可核对证据 |
| --- | --- |
| HTTP 报告闭环 | 服务端领取身份用于本地执行；真实输入进入独立工作区，报告文件和格式检查通过，SQLite 先保存结果，HTTP 接收结构化输出 |
| HTTP 代码闭环 | 从真实 bare remote 初始化，检查、提交并推送；远端分支内容和提交数量与结果证据一致 |
| 领取确认丢失 | 事务已分配、HTTP 响应被切断，经心跳找回同一 runId，仅一次 Agent 工作 |
| 离线与结果确认丢失 | 切断客户端 HTTP 后仍完成本地 Git；SQLite 关闭重开后补报，服务端已提交但响应丢失，再收到 duplicate 回执；结果和远端提交保持不变 |
| SQLite 崩溃窗口 | 结果与终态一起提交，执行器最终阶段尚未确认时重开即读取终态；新子进程通过公开存储入口读回同一结果；旧结果不能改写 |
| 迁移与参数化 | 新库启动迁移及反复重开，拒绝缺号／未来迁移；中文、引号和 SQL 形状文本完整往返 |
| 显式继续／重试 | 重建管理程序后先报告待核对，无自动 Agent 调用；保留模拟依赖的归属时核对原会话和工作区，继续同版或重试下一版 |
| 发布核对 | 已独占发布但记录未保存时找回同版；未完成 staging、会话归属缺失和版本篡改均无检查、无结果、无交付 |
| 人工等待与名额 | 原因和准确会话可查询；默认一个／配置两个名额均阻止超额领取；停止接单继续等待回答，完成并确认结果后退出 |
| 取消／期限 | 请求与确认分开；仍活动的模拟回调阻止停止确认及释放名额；显式确认后才上报 cancelled；等待计入期限，长轮询不拖延本地超期 |
| HTTP 挂起 | 心跳在真实 HTTP 边界挂起时，本地等待仍超期并保存结果；另一个 SQLite 写连接可用，释放网络后补报 |
| 文件传输未建立 | 本地报告产物及版本保留，服务端拒绝成功结果，执行仍 assigned，补报和原因可观察；不把本地路径当作服务端已收文件 |

## SQLite 与 Git 故障矩阵

HTTP 用例在提交、交付证据保存、推送、进入后置检查的阶段保存四处分别注入执行前失败及成功后确认丢失，同时阻断待核对记录写入。关闭重开 SQLite 后只读取最后落盘记录，重建客户端及 Git 交付对象，再显式继续同版。

八项用例均核对中断发生、持久阶段、准确会话、成果版本、本版检查、私有版本引用、提交及 bare remote 内容。恢复后 Agent、提交和成功推送各一次；同版 HTTP 结果成功接收。随后通过本地执行器显式继续下一版，核对父提交与旧版内容、结果不变。当前服务端没有已完成执行的重试协议，因此第二版的本地验证不作为新的服务端终态上报。已有跨版本推送失败组合仍由本地 Git 回归覆盖。

矩阵保留仍持有原目录和会话归属的模拟依赖，重建存储、执行器及客户端。SQLite 的跨进程读回已经运行，但这不证明真实 Agent 和文件执行范围可在进程退出后恢复；新的默认模拟依赖没有归属证据时保持待核对。真实 Codex 的持久 admission、原生交互与全链路由 #8 验收。

## 诊断与限制

立即停止的回归先发现管理程序等待领取和轮询期限，现通过中止 HTTP 和计时等待退出。随后定位到测试服务关闭时遗留 TCP 连接，诊断确认管理程序已停止而挂起发生于 `app.close()`；夹具在 route preClose 等待领取事务结束之后关闭其拥有的连接。五次连续中止长轮询保留原始延迟断言，并已移除临时诊断输出。

本地等待的调度独立于 HTTP；避免挂起请求或较长轮询延后期限。未解决的通信错误按操作保留，正常心跳或主动停止不能掩盖被拒绝的结果补报。

`pnpm hooks:install` 检测到已有备份且 bootstrap 带用户前置入口，因而保留现有文件并拒绝自动覆盖；现有 hook 已串联版本管理中的 Raven 检查及原 hook。本轮不修改用户钩子。完整检查执行时先暂存完整改动，测试树必须与待提交树一致。

未调用真实 Codex、个人会话数据库、managed worktree 或外部仓库；模拟结果不替代真实 Codex 验收。没有进行物理断电、整机重启、Linux 或独立 CLI 发布验证。文件流式传输、已完成任务的服务端重试及真实适配器由后续切片承担。

驱动依据：[Node.js 24.15.0 SQLite](https://nodejs.org/download/release/v24.15.0/docs/api/sqlite.html)。连接收尾依据：[Fastify close 与 forceCloseConnections](https://github.com/fastify/fastify/blob/v5.12.5/docs/Reference/Server.md)。
